# xImJxstinn Stream Tools

Schlankes OBS-Plugin von **xImJxstinn**: **Viewer Counter** und **Multichat** (Twitch + TikTok) direkt in OBS.

## Funktionen
- **Dock „xImJxstinn Viewer Counter“** – Twitch-, TikTok- und Gesamt-Zuschauer live
- **Dock „xImJxstinn Multichat“** – Twitch- und TikTok-Chat in OBS (schreiben, Nachrichten hervorheben)
- **＋ Overlays einfügen** – Viewer Counter, Chat, Alerts oder hervorgehobene Nachricht mit einem Klick in die aktuelle Szene
- **MultiStream Hub** startet und beendet sich automatisch mit OBS
- **Automatische Updates** beim OBS-Start

## Installieren
1. OBS schließen.
2. Unter **Releases** den Installer `ximjxstinn-streamtools-…-windows-installer.exe` ausführen.
3. OBS starten → **Docks** → „xImJxstinn Viewer Counter“ und „xImJxstinn Multichat“ einblenden.

Der MultiStream Hub muss einmal über `start.bat` eingerichtet worden sein. Den Ordner findet das Plugin meist selbst (⚙).
